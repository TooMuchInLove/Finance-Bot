# Finance-Bot
A financial bot in Telegram helps you quickly and conveniently manage your personal budget 💰, track expenses 📊, create and monitor savings plans 🏦, and receive useful financial tips 💡.

### Description of branches

01. `feature/`: new features and functions;
02. `bugfix/`: bug fixes;
03. `hotfix/`: urgent fixes in production;
04. `release/`: preparing releases;
05. `refactor/`: code refactoring;
06. `docs/`: changes in documentation;
07. `chore/`: tasks not directly related to the code (for example, updating dependencies);
08. `ci/`: CI/CD related changes;
09. `perf/`: performance improvements;
10. `style/`: styling and formatting;
11. `test/`: adding and changing tests;
